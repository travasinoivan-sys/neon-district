# Neon District

Una demo 3D originale per browser, senza asset o marchi ufficiali.

## Avvio

Apri `index.html` direttamente oppure avvia un server locale:

```bash
python3 -m http.server 8080
```

Poi visita `http://localhost:8080`.

## Controlli

- **WASD / frecce:** movimento
- **Shift sinistro:** corsa
- **Controller:** levetta sinistra per muoversi

La levetta sinistra viene rilevata automaticamente tramite Gamepad API.
